# Kamole Coffee House

A mobile-friendly coffee house website built with HTML, CSS, and vanilla JavaScript. No build tools or installation are required.

## Open the website

Open `index.html` in a modern browser. An internet connection is needed for hosted fonts, photos, icons, and the embedded map.

## Current features

- Responsive home page with menu, story, gallery, location, and contact sections
- English, Amharic, and Afaan Oromo language options
- Light and dark themes, saved in the browser
- Mobile navigation, scroll-to-section links, and reduced-motion support
- Opening status based on the hours currently shown on the site
- Contact form that prepares an email in the visitor’s email app
